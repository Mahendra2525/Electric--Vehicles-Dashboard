##🚗⚡ Electric Vehicle Data Analysis Dashboard | GitHub Project

###📊 Project Overview:
This dashboard provides a comprehensive analysis of EV adoption trends, vehicle distribution, and key performance metrics across different states and manufacturers.

###🔢 Key Insights from the Dashboard:

Total Vehicles Analyzed: 130,816
Battery Electric Vehicles (BEV): 104,850 (80.2%)
Plug-in Hybrid Vehicles (PHEV): 25,966 (19.8%)
Average Electric Range: 73.10 miles

###📈 What the Dashboard Covers:

EV growth trend by model year (2011–2024)
Top manufacturers (Tesla, Nissan, Chevrolet, Ford, etc.)
Top models (Model Y, Model 3, Leaf, Model S, etc.)
State-wise distribution of electric vehicles
CAFV eligibility analysis

🛠️ Tools & Skills Used:

Tebleau (Dashboard creation)
Data cleaning & transformation
Data modeling
Interactive visualization
